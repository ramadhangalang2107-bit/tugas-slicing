# 🌐 GAMPRIDE - Personal Portfolio & Slicing Showcase

Website portofolio personal yang responsif, interaktif, dan dibangun murni menggunakan **Vanilla Web Technologies** (tanpa *framework* CSS maupun JavaScript). Website ini dirancang untuk memamerkan hasil *slicing* antarmuka web, keterampilan, dan latar belakang pengembang.

---

## 🚀 Fitur Utama

- **DarkMode / LightMode Toggle**: Pengubahan tema secara dinamis memanfaatkan *CSS Variables* dan manipulasi DOM[cite: 1, 2].
- **Responsive Navigation**: *Header* melayang (*sticky navbar*) dengan menu *hamburger* interaktif pada tampilan *mobile*[cite: 1, 2].
- **Dynamic Project Filtering**: Filter kategori proyek (*Landing Page*, *Dashboard*, dll.) secara *real-time* tanpa memuat ulang halaman[cite: 1, 3].
- **Contact Form Handling**: Validasi dan tanggapan (*feedback*) status pengiriman pesan dinamis menggunakan JavaScript[cite: 1, 3].
- **Responsive Layout**: Menggunakan kombinasi CSS Grid dan Flexbox untuk tampilan optimal di berbagai ukuran layar (*Desktop*, *Tablet*, *Mobile*)[cite: 2, 3].

---

## 🛠️ Teknologi yang Digunakan

* **HTML5**: Struktur semantik elemen web[cite: 3].
* **CSS3**: Layouting (Flexbox & CSS Grid), *Media Queries*, dan *CSS Variables* untuk penanganan *theming*[cite: 2, 3].
* **JavaScript (ES6+)**: Manipulasi DOM, penanganan *event*, dan *filtering* data[cite: 1, 3].
